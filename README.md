# 👁️ Invisible Entity Detector

**Версия:** 1.0.1  
**Автор:** wertyu  
**Для Minecraft:** 1.20.1  
**Требуется:** Fabric Loader + Fabric API

---

## 📖 Описание

Мод **Invisible Entity Detector** позволяет видеть всех игроков и мобов, даже если они используют эффект невидимости (Invisibility). Больше никаких скрытых врагов!

---

## ✨ Возможности

- ✅ **Показывает всех невидимых игроков**
- ✅ **Показывает всех невидимых мобов** (зомби, скелеты, криперы и т.д.)
- ✅ **Показывает всех невидимых животных**
- ✅ **Работает автоматически** - никаких настроек не требуется
- ✅ **Работает только на клиенте** - не влияет на сервер

---

## 📦 Установка

### Требования:

1. **Minecraft 1.20.1**
2. **Fabric Loader 0.14.22+**
3. **Fabric API** (последняя версия для 1.20.1)

### Шаги установки:

1. **Установите Fabric Loader:**
   - Скачайте с: https://fabricmc.net/use/installer/
   - Выберите версию Minecraft 1.20.1
   - Установите

2. **Установите Fabric API:**
   - Скачайте с: https://modrinth.com/mod/fabric-api
   - Версия для Minecraft 1.20.1
   - Поместите JAR в папку `mods`

3. **Установите мод:**
   - Скачайте `invisibleplayer-1.0.1.jar`
   - Поместите в папку `.minecraft/mods/`
   - Запустите игру

### Структура папки mods:

```
.minecraft/
└── mods/
    ├── fabric-api-0.88.1+1.20.1.jar
    └── invisibleplayer-1.0.1.jar
```

## 🎮 Как использовать

### Автоматическая работа:

Мод работает **автоматически**! Просто установите его и играйте.

- Все невидимые игроки будут видны
- Все невидимые мобы будут видны
- Никаких настроек не требуется

### Проверка работы:

1. Зайдите в игру
2. Попросите друга использовать зелье невидимости
3. Вы должны видеть его, даже если он невидим!

## 🐛 Решение проблем

### Мод не загружается:

1. Проверьте версию Minecraft (должна быть 1.20.1)
2. Убедитесь, что установлен Fabric API
3. Проверьте версию Fabric Loader
4. Посмотрите логи в `.minecraft/logs/latest.log`

### Мод не работает:

1. Убедитесь, что мод загружен (в главном меню должно быть "Fabric")
2. Проверьте, что у игрока/моба действительно есть эффект невидимости
3. Попробуйте перезапустить игру

### Игра не запускается:

1. Удалите мод из папки `mods`
2. Проверьте, что все зависимости установлены
3. Попробуйте запустить без других модов

## ⚠️ Важные предупреждения

### ⛔ Правила серверов:

- **НЕ используйте** на PvP серверах без разрешения администратора
- **НЕ используйте** на соревновательных серверах
- Это может считаться **читом** на некоторых серверах
- Используйте только там, где это **разрешено**

### 🔒 Безопасность:

- Мод работает только на **клиенте**
- Не отправляет данные на сервер
- Не изменяет игровую логику сервера
- Не влияет на других игроков

## ❓ Часто задаваемые вопросы

**Q: Мод работает на сервере?**  
A: Нет, только на клиенте. Другие игроки не увидят, что вы используете мод.

**Q: Можно ли отключить мод в игре?**  
A: Пока нет, но планируется добавить настройки через конфиг.

**Q: Работает ли с OptiFine?**  
A: Да, должен работать, но не тестировалось.

**Q: Показывает ли мод игроков в режиме спектатора?**  
A: Нет, мод работает только для живых сущностей с эффектом невидимости.

**Q: Влияет ли на производительность?**  
A: Минимально. Мод просто изменяет рендеринг невидимых сущностей.
